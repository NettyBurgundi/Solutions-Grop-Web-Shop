# Solution Group Web Shop

Grundstruktur für das Webshop-Projekt.

## Ordner

- `docs/` – Projektdokumentation
- `src/` – Anwendungscode
- `public/` – statische Dateien
- `uploads/` – Dateien, die zum Projekt hochgeladen werden sollen
- `tests/` – Tests

Die `.gitkeep`-Dateien halten leere Ordner in Git sichtbar. Dateien in `uploads/` werden nicht ignoriert und können mit dem Projekt auf GitHub hochgeladen werden.
