# Solution Group Web Shop

Eine responsive, statische Website auf Grundlage der Datei `ZTY`.

## Seiten und Funktionen

- `index.html` – Startseite für Büromöbel, Eventmanagement und Webshops
- `produkte.html` – Beispielprodukte mit lokal gespeichertem Warenkorb
- `kontakt.html` – Kontaktformular-Demo
- `css/style.css` – Layout und responsive Gestaltung
- `js/script.js` – Warenkorb und Formularhinweis

Die Produktdaten und Preise sind Beispiele. Der Warenkorb ist nur eine lokale Vorschau; Bestellungen, Zahlungen und E-Mail-Versand benötigen noch eine Server- oder Dienst-Anbindung. Das Kontaktformular verschickt ausdrücklich keine Nachricht.

Die Website kann direkt über `index.html` geöffnet oder als GitHub-Pages-Website veröffentlicht werden.

## Projektordner

- `docs/` – Projektdokumentation
- `src/` – Platz für weitere Anwendungslogik
- `public/` – zusätzliche statische Dateien
- `uploads/` – Ablage für hochzuladende Dateien
- `tests/` – Tests
